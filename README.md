# ট্যালেন্ট সার্চ ডিপার্টমেন্ট (Talent Search Department)

যেকোনো মানুষ যেখানে নিজের প্রতিভা সবার সামনে প্রকাশ করতে পারে — এমন একটি সহজ ওয়েবসাইট।

A simple website where anyone can showcase their own talent.

## বৈশিষ্ট্য (Features)

- **প্রতিভা যোগ করুন** — নাম, বিভাগ, শিরোনাম, বর্ণনা এবং ঐচ্ছিক ছবি/ভিডিও ও যোগাযোগের লিংক সহ একটি ফর্ম।
- **গ্যালারি** — জমা দেওয়া সব প্রতিভা কার্ড আকারে, বিভাগ অনুযায়ী ফিল্টার সহ।
- **মুছে ফেলা** — নিজের যেকোনো এন্ট্রি সরিয়ে ফেলার সুবিধা।
- **থিম** — লাইট ও ডার্ক মোড টগল।
- **রেসপন্সিভ** — মোবাইল, ট্যাবলেট ও ডেস্কটপে সুন্দরভাবে দেখা যায়।
- সম্পূর্ণ স্বয়ংসম্পূর্ণ (self-contained) — কোনো বাহ্যিক লাইব্রেরি বা বিল্ড ধাপ লাগে না, শুধু একটি `index.html`।

## বিভাগসমূহ (Categories)

গান ও সংগীত, নাচ, অভিনয়, চিত্রাঙ্কন, লেখা ও কবিতা, খেলাধুলা, রান্না, প্রযুক্তি, অন্যান্য।

## কীভাবে চালাবেন (Run locally)

`index.html` ফাইলটি যেকোনো ব্রাউজারে খুলুন। শেষ।

## GitHub Pages-এ ডিপ্লয়

সেটিংস → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` নির্বাচন করুন। কিছুক্ষণ পর সাইটটি এখানে লাইভ হবে:

`https://<your-username>.github.io/<repo-name>/`

## একটি নোট (Important note)

এটি একটি ক্লায়েন্ট-সাইড সাইট। কেউ যা জমা দেন তা তাঁর নিজের ব্রাউজারে (`localStorage`-এ) সংরক্ষিত থাকে, তাই অন্য দর্শক শুধু নিজের জমা করা এন্ট্রিই দেখতে পান। সবার জমা সবার কাছে দেখাতে হলে একটি ব্যাকএন্ড (ডেটাবেস + সার্ভার) প্রয়োজন।
